# WEEK - 10  House Sale Price Analysis

##  Project Overview
House Sale Price Analysis is a Data Science project that analyzes house sales data to understand the factors affecting house prices.

This project uses Python libraries to perform data analysis and visualization. It studies the relationship between house prices, living area, property grade, condition, location, waterfront, and renovation status.

## Objectives
- Analyze house sale prices.
- Understand the relationship between living area and price.
- Identify underpriced and overpriced properties.
- Compare house prices based on grade and condition.
- Analyze waterfront property prices.
- Study the effect of property age and renovation on prices.
- Visualize house price distribution.

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

##  Dataset
**Dataset Name:** kc_house_data.csv

The dataset contains house sales information, including:
- House ID
- Price
- Living Area
- Property Grade
- Property Condition
- Waterfront
- Year Built
- Renovation Year
- Latitude and Longitude

##  Project Implementation

### 1. Data Loading
Imported the dataset using Pandas.

### 2. Data Visualization
Used scatter plots and regression plots to understand the relationship between house prices and living area.

### 3. Price Analysis
Calculated price per square foot and identified unusual underpriced and overpriced properties.

### 4. Grade and Condition Analysis
Compared house prices based on property grade and condition using statistical analysis and box plots.

### 5. Waterfront Analysis
Compared the prices of waterfront and non-waterfront properties.

### 6. Location Analysis
Visualized geographical house price distribution using latitude and longitude.

### 7. Property Age and Renovation Analysis
Calculated property age and compared renovated and non-renovated house prices.
