# House Sale Data Analysis

## Project Description
This project analyzes house sale data using Python to understand property prices, house features, renovation details, and price outliers.

## Objectives
- Analyze house prices and property features.
- Visualize bedrooms, living area, grade, and year built.
- Calculate property age and price per square foot.
- Identify and handle missing or invalid values.
- Detect price outliers using the IQR method.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Dataset Features
- Price
- Bedrooms and bathrooms
- Living area and lot area
- Grade
- Year built
- Renovation year
- Sale date

## Project Workflow
1. Import Python libraries.
2. Load the house sale dataset.
3. Explore and summarize the data.
4. Visualize property features.
5. Calculate property age and price per square foot.
6. Handle missing and zero bedroom/bathroom values.
7. Analyze renovation details.
8. Detect price outliers using IQR.

## Expected Outcome
The analysis helps understand house price distribution, property characteristics, renovation patterns, and unusual sale prices.

## Conclusion
This project uses data analysis and visualization techniques to explore house sale data and identify useful patterns in property prices.
